# Couple photos

Drop your photos in this folder using these exact filenames and they'll appear
automatically on the site — no code changes needed:

```
photo-1.jpeg
photo-2.jpeg
photo-3.jpeg
photo-4.jpeg
photo-5.jpeg
photo-6.jpeg
```

Recommended: portrait crop, roughly 4:5 aspect ratio, at least 800px wide.
Until a file exists, that slot shows a "Photo coming soon" placeholder.
